# Format Programs

**Unit:** Unit 4: Format Programs

## Definition

A format program is a licensed television concept adapted for another country.

## Core Idea

The main structure stays the same, while local details such as language, hosts and participants can change.

## Example

*1 vs 100* keeps the same quiz rules and visual identity, but each country uses local hosts and participants.

## Benefits

- cheaper and less risky than creating a completely new program
- can be adapted for local audiences
- uses local performers and production workers

## Difference from a Canned Program

A format is produced again and adapted locally. A canned program is exported as a completed program.

## How to Use It in an Answer

Format programs show that television can be global and local at the same time. The program structure travels globally, while local producers adapt the cultural details.

## Possible Questions
