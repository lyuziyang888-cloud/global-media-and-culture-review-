# Western-Centric Approaches

**Unit:** Unit 6: Media Capacity
**Exam priority:** CORE - know the definition and one case

## Memorise This

A Western-centric approach treats Western experience, power and standards as the main model for explaining global media.

## Detailed Definition

A Western-centric approach treats Western experience, power and standards as the main model for explaining global media.

## Key Terms

- West versus Rest
- universalism
- peripheral producers
- Western dominance
- local agency

## Key Points

- media imperialism and NICL reveal real structural inequality
- treating Asian production only as cheap outsourced labour can erase local agency
- applying Western theories as universal standards may overlook new media centres
- Keane does not deny Western power; he asks how integration can also create opportunities for emergence

## PPT Case

**Case:** East Asian media capacity

**Why it fits:** Keane shows that treating non-Western producers only as dependent labour can overlook local skill, infrastructure and IP development.
