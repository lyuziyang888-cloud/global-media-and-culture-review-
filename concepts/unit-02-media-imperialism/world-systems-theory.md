# World-Systems Theory

**Unit:** Unit 2: Media Imperialism
**Exam priority:** SUPPORTING - recognise it and use it when relevant

## Memorise This

World-systems theory describes a global system divided into core, semi-periphery and periphery positions, where core countries benefit from unequal relationships with less powerful regions.

## Detailed Definition

World-systems theory describes a global system divided into core, semi-periphery and periphery positions, where core countries benefit from unequal relationships with less powerful regions.

## Key Terms

- core
- semi-periphery
- periphery
- exploitation
- global hierarchy
- unequal exchange

## Key Points

- Positions are defined by unequal economic and political power.
- Core countries control more capital, technology and institutions.
- Semi-peripheral and peripheral regions participate on less favourable terms.
- Media ownership and flows can follow this hierarchy.
- The framework helps explain why global media circulation can be extensive while still being structurally unequal.

## PPT Case

**Case:** US platform dominance

**Why it fits:** Capital, infrastructure and decision-making remain concentrated in core locations while other markets participate on weaker terms.
