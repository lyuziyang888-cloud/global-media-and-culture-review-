# Unit 3 Review: Cultural Globalisation

## Unit Focus

Week 3 introduces cultural globalisation as a collection of theories that corrects media imperialism's limits. The unit focuses on audiences, meaning-making, contextual global flows, cultural proximity, contra-flows and media capitals, while retaining attention to unequal power.

## Learning Targets

By the end of this unit, you should be able to:

1. define cultural globalisation as a paradigm rather than a single theory
2. explain the limitations of media imperialism that motivated it
3. define and apply the five-scapes model
4. explain asymmetrical interdependence and cultural proximity
5. distinguish multidirectional flow and contra-flow
6. explain what makes a location a media capital
7. evaluate cultural globalisation's own limitations
8. compare both paradigms and defend a middle-ground judgement

## Main Argument Chain

```text
media imperialism cannot fully explain audiences and non-US success
-> cultural globalisation examines people, meanings and context
-> scapes, proximity, contra-flows and media capitals reveal complexity
-> multidirectional movement does not remove unequal structures
-> combine cultural change with political-economic continuity
```

### High-Value Answer Plan

For Question 8:

```text
define both paradigms
-> use cultural globalisation to explain audiences, adaptation and multidirectional flow
-> use media imperialism to examine ownership, distribution, data and revenue
-> apply one precise streaming example
-> identify what the available evidence cannot prove
-> make a case-specific judgement rather than declaring a universal winner
```

## Limitations and Counterarguments

- Cultural globalisation can remain too abstract.
- It can celebrate popular culture while overlooking ownership and power.
- Audience preference is contextual and cultural proximity does not always predict viewing.
- Contra-flows can coexist with dominant one-way flows.
- Multiple media capitals do not imply equal global capacity.
- Content origin does not establish rights ownership, revenue or distribution control.
