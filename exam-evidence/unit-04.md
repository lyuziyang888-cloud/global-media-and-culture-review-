# Unit 4: Format Programs Evidence

| Case | Use for | Key evidence | Proves |
|---|---|---|---|
| *The Traitors* | format program (U4); industrial contact zone (U5) | Core rules stay; cast, location and style change | Formats combine global consistency with local adaptation. |
| Production bible | format program; technology transfer (U6) | Instructions and flying producers guide local teams | Formats transfer production knowledge. |
| *The Masked Singer* | contra-flow (U3); format program | South Korean format gained many international adaptations | Non-Western formats can become global models. |

**Source:** Esser (2021), pp. 351-360; Week 4 tutorial.
