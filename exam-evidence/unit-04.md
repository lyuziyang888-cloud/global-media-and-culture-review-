# Unit 4: Format Programs Evidence

## *The Traitors*

**Use for:** Format program (U4); industrial contact zone (U5)

**Evidence:** Each version keeps the main rules but changes the cast, location and style.

**What it proves:** A format combines a shared global structure with local adaptation.

## Production Bible

**Use for:** Format program; technology transfer (U6)

**Evidence:** Production bibles and visiting producers guide local production teams.

**What it proves:** Format licensing transfers production knowledge as well as a program idea.

## *The Masked Singer*

**Use for:** Contra-flow (U3); format program

**Evidence:** This South Korean format was adapted in many countries.

**What it proves:** A non-Western television format can become a global production model.

**Source:** Esser (2021), pp. 351-360; Week 4 tutorial.
