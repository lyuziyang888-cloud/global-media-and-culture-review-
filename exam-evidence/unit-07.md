# Unit 7: Location and Soft Power Evidence

| Case | Use for | Key evidence | Proves |
|---|---|---|---|
| Budapest | place-making; media capitals (U3) | Rebates, studios, crews and flexible locations | Industry networks help construct a production place. |
| Government and fixers | soft power; media services | Agencies promote Hungary; fixers build relationships | Production relationships can create soft power. |
| Brisbane | place-making; representation (U1) | Tourism, Ausfilm and television present different images | The same place can have different media meanings. |

**Source:** Havens and Imre, pp. 25-41.
