# Units 1-3 Exam Question Bank

This bank removes repeated questions from the three unit files. Work from Priority A to C; do not try to answer everything at once.

## Priority A: Must Answer

### Recall

1. Define global media and explain why global and local are not simple opposites.
2. Define media imperialism and identify its central concern.
3. Explain dependency theory and the core-periphery model.
4. Define platform imperialism and explain how it updates media imperialism.
5. Define cultural globalisation and explain why it is a paradigm rather than one theory.
6. Name and define Appadurai's five scapes.
7. Define cultural proximity, contra-flow, media capital and asymmetrical interdependence.

### Extended Responses

1. Compare media imperialism and cultural globalisation. Which better explains contemporary global media?
2. Does the success of non-US media disprove media imperialism?
3. Explain how global streaming platforms can support and constrain local media industries.
4. Are global media flows one-way or multidirectional?
5. Does national identity still matter in global media?
6. Does platform imperialism represent continuity or change from classical media imperialism?

## Priority B: Apply and Evaluate

1. Use Canada's screen industry to evaluate the relationship between globalisation and local content.
2. Use Facebook to explain how platform corporations exercise power over users, markets and nation-states.
3. Use *Jane the Virgin* to explain adaptation, cultural proximity and contra-flow.
4. Use Chinese microdramas to test both media imperialism and cultural globalisation.
5. Evaluate whether media regulation can protect local production without preventing global circulation.
6. Explain why a non-US title appearing in a streaming Top 10 does not by itself prove equal global media power.

## Priority C: Challenge Questions

1. To what extent is "Western media" still a useful category?
2. Do multiple media capitals create a more equal global media economy?
3. Does cultural globalisation underestimate ownership and corporate power?
4. How can cultural homogenisation and cultural proximity occur at the same time?
5. Are audiences powerful enough to resist media imperialism?

## Three Mock Sets

### Mock Set 1

- **Short:** Define local content and one-way media flow.
- **Relationship:** Explain how streaming platforms affect local production.
- **Extended:** Which paradigm better explains Chinese microdramas: media imperialism or cultural globalisation?

### Mock Set 2

- **Short:** Define cultural proximity and platform imperialism.
- **Relationship:** Explain how one-way flows and contra-flows can coexist.
- **Extended:** Does the nation still matter when media production and distribution cross borders?

### Mock Set 3

- **Short:** Define media capital and asymmetrical interdependence.
- **Relationship:** Explain how media imperialism and cultural globalisation complement one another.
- **Extended:** Do global streaming platforms make the media economy more diverse or more unequal?

## Self-Marking Checklist

Give one point for each item present:

- accurate definition
- direct answer to the question
- explained mechanism or relationship
- precise evidence
- limitation or counterargument
- justified final judgement

For extended answers, aim for all six. More concepts do not compensate for weak explanation.
